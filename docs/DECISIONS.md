# Decisiones

1. **Aplicación aislada en `gradient-lab/`.** El workspace inicial está vacío salvo montajes internos de solo lectura; `.git` en la raíz no es un repositorio utilizable. No se alteran esos montajes ni archivos ajenos.
2. **Fuente primaria incorporada.** El usuario añadió `Cartel.pdf`; se leyó texto e imagen y se conserva copia en `docs/`. La interfaz no reutiliza escudos o logotipo NVIDIA. Solo se enlaza el documento original como fuente académica.
3. **Skills.** Ponytail guía el alcance; Impeccable es la única guía visual principal; Animate complementa únicamente timing y movimiento; planificación y TDD organizan arquitectura y pruebas; Agent Reach orienta comprobaciones GitHub y lectura de fuentes, usando la integración oficial disponible. No se activan guías visuales superpuestas ni se instalan skills.
4. **Autonomía.** El usuario entregó especificación detallada y pidió continuar integralmente sin interrumpir decisiones rutinarias. Esa instrucción sustituye las rondas de aprobación de diseño de las skills. El concepto fijado en el encargo prevalece sobre variantes aleatorias.
5. **Stack solicitado.** Vite, React, TypeScript estricto, SVG para gráficas y Three.js/React Three Fiber bajo demanda. Fórmulas semánticas con texto/HTML legible; no se añade KaTeX para fórmulas que no lo necesitan.
6. **Una fuente de verdad.** Reducer puro para estado e historial. Inputs y pesos inician un nuevo experimento; eta modifica el siguiente paso sin reescribir pérdidas anteriores.
7. **Sección y proyección honestas.** Ver `MATH_SPEC.md`: recalcular el historial sobre w₃ actual y etiquetar la proyección; las pérdidas temporales permanecen reales.
8. **Rutas hash.** Compatible con recarga directa en Pages. Sin backend, cuentas, telemetría ni cotizaciones reales.
9. **Licencia pendiente.** No se asume consentimiento de ambos autores para una licencia del trabajo original. Se conservan avisos de dependencias.
10. **Restricciones iniciales.** Shell sin acceso de red ni sockets loopback; npm no resuelve DNS. GitHub CLI informa token inválido, pero la integración GitHub reconoce HannDev2. `HannDev2/gradient-lab` devuelve 404 al comenzar. No confundir esto con un despliegue.

11. **Permisos recuperados.** Tras la actualización del usuario, red, loopback, instalación npm y autenticación GitHub CLI funcionan. Se mantiene el stack solicitado.
12. **Pruebas de revisión.** Revisor independiente confirmó cartel e historial y señaló overflow en contornos con entradas subnormales; se reemplazó la división ilimitada por intersecciones normalizadas dentro del dominio y se añadieron regresiones. El ciclo WebGL distingue desmontaje normal de pérdida real.
13. **Detector visual.** Advierte uso frecuente de Space Grotesk; se conserva la decisión tipográfica documentada, combinada con IBM Plex Mono solo para datos. No hay otros hallazgos deterministas.
14. **v2 aislada.** La evolución visual vive en `feature/visual-v2` y se entrega mediante PR. El usuario debe aprobar la fusión antes de reemplazar Pages; el workflow omite publicación en eventos de PR.
15. **Mismo cálculo, nuevas representaciones.** No se modifican motor ni reducer. El escenario oscilatorio compone reinicio y cambio de tasa existentes. La curva de errores representa estados reales, y su factor q procede de `stability`.
16. **Coste gráfico controlado.** La portada reutiliza la escena lazy existente; no incorpora librerías. Hero SVG por defecto en teléfonos y 3D opcional; Canvas a demanda y desmontaje fuera de vista. No se añade postprocesado ni animación continua de geometría.
17. **Interpolación sobre la función.** Para hacer legible el desplazamiento se interpolan pesos y se vuelve a evaluar pérdida con w₃ actual, evitando interpolar alturas linealmente. La línea se aproxima con ocho subsegmentos por actualización; los estados y pérdidas históricas originales se conservan.
18. **Electric Observatory aislado.** `feature/visual-v3` parte de `a18e3b0` en v2 y su PR apunta a `feature/visual-v2`. No se fusiona PR #1 ni se publica. El workflow verifica también PR hacia v2 y mantiene el deploy omitido en todo evento `pull_request`.
19. **Luz sin postprocesado pesado.** Material emisivo, color por pérdida real, Fresnel aditivo, líneas y una textura de halo local. No se añade bloom ni otra dependencia. La trayectoria usa centros de sección evaluados y el grosor solo mejora visibilidad. Canvas a demanda; se conserva SVG hasta que termina el primer fotograma del hero.
20. **Presentación con las mismas operaciones.** `Cinema` reutiliza `ChapterExperiment`, capítulos y visualizaciones; la escena de entrenamiento recibe el reducer de `App`. La reproducción es opcional y se pausa al perder foco, ocultar la pestaña o usar controles matemáticos. Salir conserva el experimento; restaurar es una acción explícita. Un callback de snapshot mantiene ascenso/descenso y paisaje sincronizados.
21. **Cifras exactas durante la animación.** Se anima la aparición de la cifra calculada, nunca valores intermedios independientes de error y pérdida. La identidad L=e²/2 sigue siendo cierta en todas las lecturas visibles.
22. **Evidencia de rendimiento limitada al entorno.** Se comparan builds v2/v3, gzip, FCP e intervalos rAF. Chromium identifica SwiftShader incluso sin forzar ANGLE; no se presenta la mediana de rAF como FPS efectivos. La grabación se realiza aparte para no contaminar las medidas. Playwright usa dos workers para evitar saturar el renderizador software en CI.
23. **Ayuda contextual nativa.** Las tres métricas explican fórmula, signo y unidades con popover de plataforma y CSS; teclado, toque, Escape y cierre exterior sin añadir una librería de tooltips. Se comprueba el flujo en ambas clases de pantalla.
